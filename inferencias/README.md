# Entrelinhas — aprender a inferir

Aplicação educativa autónoma para treinar a leitura inferencial com textos literários e dos media, dirigida a alunos do ensino obrigatório, com incidência no 3.º ciclo.

## Publicar no GitHub Pages

1. Coloca `index.html` na raiz de um repositório GitHub (ou numa pasta publicada por GitHub Pages).
2. Em **Settings → Pages**, escolhe a origem de publicação pretendida.
3. Abre o endereço indicado pelo GitHub Pages.

Não requer instalação, servidor, conta ou dependências externas. O progresso e as reflexões ficam guardados localmente no navegador; não são enviados para um servidor. Os textos de treino foram escritos para esta aplicação.

## Conteúdo

- Estratégia E–C–I–L: encontrar evidências, conectar conhecimento, inferir e limitar a conclusão.
- Oito textos originais: quatro literários e quatro dos media.
- Questões com respostas comentadas, pistas, explicação e armadilhas de leitura.
- Reflexão escrita e comparação com uma resposta possível.
- Filtros por tipo de texto, missões por competência, resumo descarregável e progresso local.
- Interface adaptável a computador, tablet e telemóvel.
